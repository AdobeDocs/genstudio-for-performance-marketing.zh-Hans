# AI助理概述

[!DNL GenStudio for Performance Marketing]通过模型上下文协议(MCP)连接到支持的AI助理。 连接后，您可以通过自然语言对话查询广告效果、组合创意和发布批准的广告。

## 支持的AI助理

您可以通过以下受支持的AI助手路径进行连接：

| AI助手 | 连接路径 |
|---|---|
| Adobe CX Enterprise Coworker | 由您的组织管理的本机连接 |
| 克劳德 | 远程MCP连接器 |
| Web上的ChatGPT | 处于开发人员模式的远程MCP连接器 |
| 法典 | 从命令行配置的远程MCP连接 |
| 作者 | 远程MCP自定义连接器 |
| Microsoft Copilot | 使用Microsoft指南配置的远程MCP连接 |

有关设置指导，请参阅[连接AI助手](connect-ai-assistants.md)。

## 功能

一旦连接起来，AI助手可以在三个领域提供帮助：

- **见解：**&#x200B;获取标题KPI，查找表现最佳和最差的广告，了解广告按特定方式表现的原因，并接收以您的绩效数据为基础的建议。
- **创建：**&#x200B;浏览模板，从模板或推荐中汇编可编辑的草稿，并共享该草稿以供审阅和批准。
- **激活：**&#x200B;查找已批准的体验，解决其发布目标，并将其发布到连接的渠道。

支持的渠道因功能而异。 分析涵盖了大多数报表的Meta、LinkedIn和Innovid。 自定义转化指标涵盖Meta和LinkedIn。

“创建”包含Meta、LinkedIn、Display、TikTok和YouTube。 激活涵盖Meta、LinkedIn和Google Campaign Manager 360。 有关每个工具的渠道支持，请参阅[AI助手工具引用](tools-reference.md)。

## 访问和权限

AI助手功能通常适用于已启用[!DNL GenStudio for Performance Marketing]的客户。 您需要一个拥有产品访问权限的有效Adobe帐户。

该连接使用您的Adobe身份并尊重您现有的产品权限。 您只能访问您的帐户已可以查看的组织、付费媒体帐户、营销活动和数据。

每个连接的作用域都限于一个Adobe Identity Management System (IMS)组织。 需要切换时重新连接并选择其他组织。
